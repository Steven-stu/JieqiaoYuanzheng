界桥远征 V0.6 —— 卡面返工清单（实测数据）
生成时间：2026-11-04 18:50
检测对象：Assets/Resources/Art/units/ 下 192 张卡面（全部已入库、全部透明、全部 384×512 = 3:4）
检测方法：逐张统计「不透明像素占比」「主体包围盒（横×纵向占画布比例）」「主体中心位置」「平均亮度」
数据明细：reports/卡面构图体检.csv（192 行）

为什么需要返工：卡框是 3:4（棋盘 90×120 / 手牌 96×128 / 预备 81×108 / 详览 330×440），
卡面以 cover 方式铺满；若人物/物件在画面里占比太小（大量透明），在卡框里就会显得"空、小、飘"，
再叠上卡底的深色，观感会像一张没画完的卡。

参考门槛（本清单的判断标准）：
  · 不透明像素占比 < 20%      → 严重空洞（A 级）
  · 不透明像素占比 20%–25%    → 偏空（B 级）
  · 主体纵向占比 < 55%        → 主体偏小（B 级）
  · 场景/横构图卡（遭遇 C 类、横向 90%+）天然上下留白，不算问题（C 级，仅供参照）

════════════════════════════════════════════════════════════
返工时的通用要求（避免二次返工）
════════════════════════════════════════════════════════════
1. 画布：竖版 3:4（建议 1086×1448 或 543×724），透明背景，PNG。
2. 主体：纵向占画面 65% 以上，不透明实体面积占 40% 以上（人物类 ≥ 50%）。
3. 构图：主体中心横向落在 35%–65% 之间，不要贴边。
4. 亮度：平均亮度控制在 0.30–0.65（当前 192 张平均 0.388，无偏暗/偏亮）。
5. 卡框内会叠加：顶部 30px 半透明黑条（卡名）、底部 20px 半透明黑条（攻/血），
   所以主体头顶与脚底各留 ~10% 空白，避免被条挡住。
6. 文件名就用卡号（如 Q08.png），放进 Assets/Resources/Art/units/ 即可自动替换，无需改代码。
