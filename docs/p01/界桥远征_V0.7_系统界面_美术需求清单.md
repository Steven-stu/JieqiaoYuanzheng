# 界桥远征 V0.7 —— 大厅与系统界面：完整交互 + 美术资源需求

生成时间：2026-11-04 20:05
用途：**给 GPT 绘制美术资源**（设计规格 + 资源清单 + 交付约定）
现状：战斗界面已经做完并在跑（对局、进化、融合、特效都在），**大厅与这 7 个系统页面还没有**。
本文档同时是界面设计稿：每个页面写清楚模块分区（方便以后写代码）与所需素材（方便画图）。

---

## 0. 屏幕地图

玩家进游戏后的完整流程：

```
启动
 └─ 标题页 Title           （Logo + 开始 + 设置）
     └─ 大厅 Home ★         （主界面：玩家信息 + 货币 + 5 个入口）
         ├─ 对战 Battle ★   （已有：战斗场景；选对手/选卡组也在大厅里做）
         │    └─ 结算 Result（胜利/失败/平局横幅 + 奖励）
         ├─ 商店 Shop
         ├─ 每日签到 CheckIn
         ├─ 卡牌图鉴 Codex
         ├─ 个人资料 Profile（对局记录 + 胜率）
         ├─ 组卡组 DeckBuilder
         └─ 交换卡牌 Trade
```

★ = 必须有；其余是本轮要补的 6 页 + 2 个系统（存档与奖励结算）。

统一设计空间：**1600×900**（与战斗界面一致，按画布高度等比缩放）。

## 11. 交付约定（照抄就能用）
