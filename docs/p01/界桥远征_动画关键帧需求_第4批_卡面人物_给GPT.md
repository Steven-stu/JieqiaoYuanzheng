## 一、这一批和前几批的本质区别（务必先看）

| | 第 1–3 批 | **第 4 批（本批）** |
|---|---|---|
| 画的是什么 | UI 控件、横幅、光环、氛围层 | **卡牌立绘里的角色本人** |
| 画布 | 各种尺寸 | **一律沿用原卡面的 384×512**（3:4） |
| 首帧要求 | 首帧＝原图 | 首帧 **＝该卡现有立绘（逐像素一致，不许重画）** |
| 中间帧 | 控件位移/发光 | **角色身体局部做小幅动作**（呼吸、眨眼、抬手、衣摆/毛发飘动） |
| 禁止 | 画文字 | 还多一条：**不改构图、不换姿势、不改画风/光源/描边**，只在原图上"加动作" |
| 透明 | 透明底 | **不透明**（与现有卡面一致，满画布插画，不留透明边） |

**最重要一条**：把现有卡面（`Assets/Resources/Art/units/<卡ID>.png`，384×512）当第 0 帧，
后面每帧只做小幅形变。判断标准：3 帧连播像呼吸/眨眼/衣摆飘；**单独看任意一帧都是"同一张画"**。

**动作幅度上限**：整体位移 ≤ 6px，单个部件（手臂/头部）旋转 ≤ 4°，缩放 ≤ 4%。
超了就会"跳"，玩家会觉得卡面在抖。

> ### ⚠ 重要例外：`B01–B44` + `G01–G16` 这 60 张**目前没有专属插画**
> 游戏里跑的是运行时生成的流程占位图（渐变+斜纹），工程 `Assets/Resources/Art/units/` 里**没有** `B*.png` / `G*.png`。
> 所以这 60 张**不适用"首帧逐像素一致"**，改成合并任务：
> - `_00` = 你**新画**的这张卡正式立绘（384×512、满画布不透明，画风/光源/描边/构图比例与既有 192 张统一）
> - `_01` / `_02` = 在 `_00` 上做呼吸/眨眼（兽另加尾/翼/触须飘动，少女加衣摆与发梢）
> - 角色定位、费用身材、进化线、可融合对象见随包的 `card_specs_B组44张.csv` / `card_specs_G组16张.csv`
>
> 其余 **192 张基础单位 + 4 张卡背 + 5 张大厅入口都有现成原图**，那部分严格按"首帧逐像素一致"处理。
