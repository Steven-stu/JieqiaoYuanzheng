## 0. 一句话背景

《界桥远征》是横版卡牌对战：玩家在 4 行 6 格的战场（我方两排 / 敌方两排）上部署单位、互相攻击，先打掉对方 20 血远征旗或第 12 轮结束时旗血多者胜。整体美术是**暮色浮岛 + 断裂星环**的奇幻基调（现有默认战斗背景 `battle_bg.png` 就是这个调子，请先看一眼再动笔）。

本次要画三类东西：

| 类 | 用途 | 数量 |
|---|---|---|
| A | 结算画面（胜利 / 失败 / 平局） | 3 张横幅 + 3 套横幅动效 + 3 套全屏特效 |
| B | 回合横幅（轮到我方 / 对手行动） | 1 套 3 帧 |
| C | 场地（战况牌）专用战斗背景 | 6 张 |

**硬性前提：所有图都不要画文字。** 文字由 Unity 按字体渲染（`轮到我方 第 3 轮`、`场地：工坊防线（我方）` 等已由代码绘制）。图里一旦有字，中文小字会糊、也没法改文案。

## 2. A 类：结算画面

### 2.1 三张横幅（A1）

`banner_*.png` 是结算时出现在棋盘正中的**大横幅**，尺寸固定 **1200×260**，四角必须透明（Unity 里会再做一次弹出缩放动画，四周留 ~20px 安全边，别让重要元素贴边）。

三种情绪要一眼可分：

| 文件 | 主题 | 建议画面 |
|---|---|---|
| `banner_victory.png` | **胜利**：击破敌方远征旗 | 暖金主色；断裂星环的碎片向上飞散、光柱从旗位升起；构图向右上抬升 |
| `banner_draw.png` | **平局**：第 12 轮结束双方旗血相同 | 青白/银灰主色；两半对称的天平或双向星光，水平构图、无高低差，表达"势均力敌" |
| `banner_defeat.png` | **失败**：己方远征旗被击破 | 暗红/铁灰主色；旗杆倾倒、余烬下沉；构图整体向下压 |

### 2.2 横幅动效（A2）

每套 **3 帧**，尺寸与 A1 相同、透明底，播放顺序 00→01→02，循环停在最后一帧。

- 三帧之间只做**小幅推进**（粒子/光晕/旗帜摆动），不要做完全不同的构图，否则会闪。
- 帧 00 = 静止版叠加一点点光；帧 02 = 最强的一瞬（用于"定格"）。

### 2.3 全屏特效（A3）

**1600×900、透明底**，叠在整个战场之上播一次（约 2 秒）。这是"最后画面好不好看"的关键，请把力气花在这。

| 文件 | 场景 | 内容要求 | 禁止 |
|---|---|---|---|
| `anim_victory_stars` | 胜利 | 从四周向中心汇聚的金色星屑 + 顶部柔光；中心区域（约中间 900×500）保持**低密度**，因为横幅和结算文字在那 | 不要满屏雪花式粒子，不要亮到看不清字 |
| `anim_defeat_vignette` | 失败 | 四周暗角 + 缓慢下沉的暗红余烬 / 裂纹；中心保持通透 | 不要整屏变暗到看不见棋盘，暗角最深处 alpha ≤ 0.55 |
| `anim_draw_veil`（新增） | 平局 | 一层青白柔光从上下两侧向中间合拢、留一道细光缝 | 不要用红色系（会像失败） |

**重要**：全屏特效中间偏左（x 300–1000, y 250–650）是棋盘与结算文字的位置，请让这一带保持半透明或纯空，只在外围做戏。

### 2.4 现在的问题（为什么要重画）

现有素材的问题是**只在角落放了几颗小星星/一圈暗红**，画面几乎没变化，看起来"没做完"；平局直接借用失败暗角，输和棋分不出来。这次要的是**情绪明确、一眼能区分三种结果**。

## 3. B 类：回合横幅

`anim_turn_banner` 现在是**一张纯蓝彩带、上面没有字**——玩家在实机里反馈"看到一条蓝色条带，不知道是干什么的"。

代码这边已经加上了文字（`轮到我方　第 3 轮` / `对手行动　第 4 轮`，28 号字，居中压在横幅上）。所以素材这样画：

- 尺寸 **600×120**，3 帧，透明底；
- 中间 x 120–480、y 24–96 这一块**必须留空或极低对比度**（字会压在这上面）；
- 装饰只放在**左右两端**：左侧可放我方色（暖金）飘带，右侧可放敌方色（冷蓝）飘带；或者做成一条两端卷起、中间镂空的横幅底框；
- 因为是同一套素材要同时用于我方/对手回合，**两端颜色要中性**（金/白/暗蓝都可），具体倾向由代码改文字颜色表达。

## 4. C 类：场地（战况牌）专用战斗背景

### 4.1 机制说明

游戏里有一类"战况"牌（F 卡），打出后**整局生效**，属于玩家自己的场地。现在打出战况后背景不变，玩家感知不到场上多了个持续效果。本次要求：**打出战况牌 → 战斗背景整块换成对应场地**，代码侧已实现（找不到图就退回默认背景并在顶部标"专用背景待补"）。

我方战况优先于对方战况；对手的场地会整体压成偏暖红调，避免和自己场地混淆。

### 4.2 六张场地清单

| 文件 | 战况名 | 卡牌效果（画面上要能看出这是"什么场地"） | 画面建议 |
|---|---|---|---|
| `battle_bg_f01.png` | **远征营盘** | 己方每轮第一次治疗单位时，治疗量 +1 | 夜宿的行军营盘：帐篷、篝火、补给箱、医疗旗；暖橙火光 |
| `battle_bg_f02.png` | **树冠战场** | 己方**后排**单位受到的主动攻击伤害减1 | 巨树树冠间的木板栈道；层层枝叶做天然掩体；青绿色 |
| `battle_bg_f03.png` | **工坊防线** | 己方**构装**单位获得坚壁 | 矮人/机械工坊：齿轮墙、锻炉、蒸汽与铁砧；铜锈+炉火橙 |
| `battle_bg_f04.png` | **血族夜宴** | 己方每轮第一次成功**汲取**时额外治疗 1 | 血族厅堂夜宴：长桌、烛台、暗红帷幕、高脚杯；酒红+烛黄 |

### 4.3 背景的硬性约束（很重要）

1. **尺寸 1672×941**（与现有 `battle_bg.png` 一致）；若你只能出 1600×900，也可以，但请**四周多留 3% 安全量**（重要元素别贴边）。
2. **中间偏左是战场格（6 格）**：x≈600–1000、y≈40–700 这一块会被卡牌盖住，请让这里**信息密度低、对比度中低**，别放主线细节。
3. **不要画文字、不要画 UI 框、不要画血条**。
4. **不能比现有默认背景更亮**：界面里还会叠一层 58% 的压暗层，太亮的背景会让卡面文字更难读。
5. **左右两侧与底部要能被 UI 压住不心疼**：左侧 x<330 是"预备/已选中/战报"面板，右侧 x>1220 是行动按钮列，底部 y>730 是手牌区（9 张卡）。
6. 六张之间要保持**同一世界观与光照逻辑**（同一片暮色天光、同样的星环远景），只是地貌与配色不同——玩家要能感到"场地变了"，而不是"换了个游戏"。

## 5. 统一美术规范

| 项 | 要求 |
|---|---|
| 风格 | 与现有默认战斗背景一致：**半写实奇幻插画**，偏低饱和、暮色光照；不要 Q 版、不要像素风（现有像素小图另有用途） |
| 主色 | 底色统一偏暗（明度中低），高光集中在一两处；避免大面积纯饱和色块 |
| 对比 | 画面最亮处不要比 UI 文字（近白）更亮；中间战场区域对比度压到最低 |
| 透明 | A 类、B 类必须真透明（PNG-32），**不要用白色/黑色冒充透明**——黑底会在游戏里变成一块黑板 |
| 文字 | 一律不画字（横幅、场地、回合横幅都一样） |
| 分辨率 | 按上面各处标注的原尺寸出图，不要放大缩略图 |
| 文件 | PNG-24/32，单文件 < 3 MB；A3 全屏特效单帧建议 < 1.5 MB |

## 7. 落地方式（执行方这边已就绪，你只要按路径给文件）

- A 类横幅：`V06UiV07.Skin("banner_victory"/"banner_draw"/"banner_defeat")`
- A 类横幅动效：`V06UiV07.PlayOnce(..., "anim_banner_*")`
- A3 全屏特效：`ShowResult()` 里按胜负分别播 `anim_victory_stars` / `anim_draw_veil` / `anim_defeat_vignette`
- B 类：`PlayTurnBanner()` 播 `anim_turn_banner`，文字由代码叠加
- C 类：`RefreshBattlefieldVisual()` 按 `Art/battle_bg_<场地ID小写>` 加载（`F03` → `battle_bg_f03`），缺图自动退回默认背景并标注

**替换现有素材即可生效，不需要改代码。** 若某套动效暂缺，画面会退化成"横幅静止 + 文字"，不会报错。

## 8. 验收标准（执行方会用实机截图核对）

1. 胜利 / 平局 / 失败三张结算画面，**遮住文字也能靠画面本身分辨**是哪种结果。
2. 全屏特效播完后，**棋盘与结算文字仍然清晰可读**（中间区域没有被粒子糊住）。
3. 回合横幅上文字清楚，且素材中间没有被自己的图案干扰。
4. 六张场地背景并排看是同一套世界观；打出战况牌后，玩家一眼能看出"场地换了"。
5. 任意一张背景图上，卡牌名称、攻血数字、左侧面板文字都保持可读（这是硬指标）。
