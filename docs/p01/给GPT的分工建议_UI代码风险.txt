二、为什么不能全交（这个工程有 8 条硬约束，通用 UI 代码几乎必踩）
════════════════════════════════════════════════════════════
1. 缩放：Canvas 用 ScaleWithScreenSize(1600×900, match 0.5)，LayoutRoot 再按「Canvas rect 高度 / 900」缩放一次。
   ❌ 常见错误：再乘 Screen.width/height → 叠两层缩放，按钮跑到屏幕外点不到（本项目真出过，3120 宽屏上按钮落在 x≈3460）。
2. 点击：全屏压暗层/背景图必须 raycastTarget = false，否则吃掉点击（真出过：Scrim 挡住响应按钮）。
3. 刚显示/新建的控件：同一帧 CanvasRenderer.absoluteDepth = -1，射线不可用；刷新与点击必须隔一帧。
4. 卡框比例固定 3:4（棋盘 90×120 / 手牌 96×128 / 预备 81×108 / 详览 330×440），改比例会让卡面裁切。
5. 卡面用 RectMask2D 裁切，不要再加 Mask（额外 stencil + 层级复杂）。
6. 控件池化：刷新只改文本/颜色/图片，禁止每帧 Destroy/Instantiate（会触发当帧射线失效 + GC）。
7. 所有可点目标都来自 engine.LegalActions()，界面只是"把合法行动画出来"。
   任何绕过它自己造的可点目标 = 玩家点了却违反规则。
8. 卡牌守恒（每方 24 主牌 + 6 预备 = 30 张）由引擎与 V06Sim.SelfCheck 每步校验；
   特效层如果"顺手"改了手牌/弃牌/装备挂载，会直接触发不变量失败。

────────────────────────────────────────────────────────────
再加上 GPT 作为聊天模型的固有局限：
  · 不能编译、不能运行、看不到画面 → 无法自测手感（缓动曲线、时长、连击节奏全靠猜）
  · 只能给文本片段 → 需要人工拼接，拼错就是编译错误或静默逻辑错
  · 看不到本工程已有 2900 行的 V06BattleUI → 极易重复实现已有功能或与既有状态机冲突
  · 无法感知性能（uGUI 每帧 rebuild、Canvas 分层、纹理体积）

【契约 1】纯视觉特效 API（我给它的现成签名，让它只填实现）
    // 文件：Assets/Scripts/UI/V06HudFx.cs
    // 约束：无状态、不改引擎与界面数据、不用第三方库、不新建 Canvas、不每帧 Update
    public static class V06HudFx
    {
        // 在世界坐标/锚点处飘一个伤害数字，t 秒后自动销毁
        public static void DamageNumber(RectTransform layer, Vector2 anchoredPos, int amount, Color color, float duration = 0.8f);
        // 目标矩形抖动
        public static void Shake(RectTransform target, float strength = 6f, float duration = 0.25f);
        // 目标图形闪一下颜色
        public static void Flash(Graphic target, Color color, float duration = 0.2f);
        // 卡牌从 A 点飞到 B 点（入场/离场）
        public static void Fly(RectTransform card, Vector2 from, Vector2 to, float duration = 0.22f);
    }
    它需要提供：只用 UnityEngine.UI + 协程（MonoBehaviour 可挂在一个空宿主上），
    不依赖 DOTween；时长/曲线写成常量便于我调。

【契约 2】信息面板（只读展示，不改数据）
    // 文件：Assets/Scripts/UI/V06CardInfoPanel.cs
    // 输入：一个只读快照结构（由我提供的填充函数），输出：无
    public struct V06CardView
    {
        public string CardId, Name, CategoryText, KeywordText, EffectText;
        public int Cost, Atk, Hp, CurrentAtk, CurrentHp, Damage;
        public string ArtPath;        // 例如 "Art/units/Q08"
        public bool CanPlayNow;
    }
    public sealed class V06CardInfoPanel : MonoBehaviour
    {
        public void Build(RectTransform parent);   // 一次性建控件
        public void Show(V06CardView v);           // 刷新内容
        public void Hide();
    }
    它只需要负责"排版与视觉"，卡数据由我在界面里填。
