## 二、规则（和上一批完全一样，务必遵守）

1. **首帧必须与该卡现有立绘逐像素一致**——原图就在工程里：
   `Assets/Resources/Art/units/<卡ID>.png`（384×512，满画布不透明）。
   你上批交付的首帧已经对上了，这批继续保持。
2. **画布 384×512、不透明底、不留透明边**；同一张卡所有帧尺寸完全一致。
3. **不改构图、不换姿势、不改画风/光源/描边**，只在原图上"加动作"。
4. 动作幅度：整体位移 ≤ 6px，单部件旋转 ≤ 4°，缩放 ≤ 4%。
5. **不画文字、数字、图标里的字**（费用/攻/血都由代码画在最上层）。
6. 出手帧要有"前压感"：重心前倾 ≤4°、持械手前送 4–6px、发/衣摆向后 5–6px；
   受击帧要"后仰"：后仰 ≤3°、发/摆向前 4px、**整体压暗 8%**（在原图上调暗，不要加阴影层）。
