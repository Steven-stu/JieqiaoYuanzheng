# 界桥远征 —— 音效**全量替换**清单（40 个槽位，供逐项挑选）

> **这份清单的定位改了**：不再是"补几个缺的"，而是**把游戏里每一个音效槽位全部重做**。
> 现在游戏里跑的 17 个音效是 8-bit 芯片音（Juhani Junkala），风格与中世纪奇幻卡牌不搭，**全部替换**。
>
> 每个槽位我都标了：**在哪响 / 现在用的是哪个旧文件 / 要什么听感 / 时长上限 / 重要程度**。
> 我下载候选后会按 `R01`…`R40` 建文件夹，每个槽位放 **2–4 个候选**，你听一遍直接报编号（例如「R07 选第 3 个」）。

## 一、现在的音效槽位是怎么用的（代码事实）

| 旧文件名 | 代码里在哪些地方响 |
|---|---|
| `sfx_click` | 全站所有按钮（`UiKit.Button` 统一挂） |
| `sfx_back` | 购买失败、返回操作 |
| `sfx_coin` | 购买成功、开卡包、**增益 buff**、**回响 echo** |
| `sfx_confirm` | 签到领取、**召唤 summon** |
| `sfx_hit` | 斩击 slash |
| `sfx_shoot` | 射击 shot |
| `sfx_laser` | 法术 spell |
| `sfx_flag` | 旗 flag |
| `sfx_guard` | 格挡 guard / 墙 wall |
| `sfx_heal` | 治疗 heal / 汲取 drain |
| `sfx_death` | 阵亡 death |
| `sfx_evolve` | 进化 evolve |
| `sfx_fuse` | 融合 fuse |
| `sfx_explosion` | 余烬 ember / **压力阶段 pressure** |
| `sfx_win` / `sfx_lose` | 结算 |

**关键问题**：`sfx_coin` 同时给"金币"和"buff/echo"，`sfx_confirm` 同时给"签到"和"召唤"，
`sfx_explosion` 同时给"爆炸"和"压力警告"——听感完全不同的场景共用一个音。
所以这次替换会**把它们拆开**，槽位从 15 个扩到 40 个。

## 四、统一风格建议（我会按这个方向筛候选）

- **音色家族**：木质（桌面、木杆）+ 金属（剑、盾、硬币）+ 羊皮纸（卡牌、卷轴）+ 皮革布料 + 号角/钟琴（提示与结算）
- **不要**：8-bit 芯片音、卡通"嗖/哔"、大型电影爆炸、带人声喊叫（除进化可能有"喝"）
- **响度**：全部做 **-16 LUFS 左右归一化**，避免有的音效特别吵
- **格式**：我统一转 **WAV 44.1kHz / 16bit**，削掉首尾静音（<5ms），保留自然尾音
