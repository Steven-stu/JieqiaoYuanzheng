## 二、规则（和前几批一致）

1. **首帧必须与该卡现有立绘逐像素一致**：`Assets/Resources/Art/units/<卡ID>.png`，384×512，满画布不透明。
2. 不透明底、不留透明边、不画文字数字；同卡所有帧尺寸一致。
3. **不改构图/姿势/画风/光源/描边**，只在原图上"加动作"。
4. 动作幅度：整体位移 ≤ 6px，单部件旋转 ≤ 4°，缩放 ≤ 4%。
5. 出手 = 前压 ≤4°、持械手前送 4–6px、发/摆向后 5–6px；受击 = 后仰 ≤3°、发/摆向前 4px、整体压暗 8%。
6. **战术卡（C 组）不是人物**，只要"卡面微动"：2 帧，`_00` = 原图，`_01` = 画面主体上的光效/烟雾/纹理轻微变化（亮度 +15% 或位置 2–3px），**不要动构图、不要加新元素**。

## 五、B 组：8 张衍生单位（48 帧）

衍生单位不会出现在手牌，只在棋盘上出现，所以**待机帧要更"活"**（它们通常体积小、动作要明确）：

`T01` 茸角灵鹿、`T02` 微光侍灵、`T03` 战帮帮手、`T04` 夜蝠群、
`T05` 荒原猎犬、`T06` 守备无人机、`T07` 风翼雏龙、`T08` 维修微机

- 待机 3 帧：`_00` = 原图；`_01` 吸气 + 眨眼（动物类）/ 灯闪（机械类）；`_02` 呼气回落。
- 出手 2 帧：小型单位动作可以**幅度稍大**（≤ 8px），因为它们在棋盘格上占比小。
- 受击 1 帧：后仰 + 压暗 8%。
- `T04` 夜蝠群是群体，出手让"群"整体前冲并略微散开；`T08` 维修微机是机械，用灯光与机械臂。
