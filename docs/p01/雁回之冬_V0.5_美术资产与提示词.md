# 雁回之冬 V0.5 · 玩家可见界面与美术资产生产包

**用途**：把"玩家能看到的一切"拆成可下单的资产，并给出可直接粘贴给 GPT 出图的专业提示词。
**风格**：精细绝区零式二次元（cel-shade + 硬边阴影 + 粗描边 + 高对比 + 街头潮流剪裁），**但一切造型服从本作设定**（霁原冻土 / 桥 / 炉 / 苔 / 火盐）。

---

## 0. 这套东西怎么用（三步）

```
① 你 → GPT：把「§3 母提示词」+「§4 某条资产的提示词」丢进去，出图
② 我 ← 图：按「§13 验收清单」核对（设定一致性 / 色板 / 无文字 / 安全区 / 描边）
③ 我 → Unity：按「§14 接线表」把图接进原型（切图、九宫格、图集）
```

**三条铁律（比提示词更重要）**

1. **出图不许带文字**。所有牌名、费用、攻生、说明都由程序渲染。图上出现任何字母数字＝废图。
2. **插图不许自己画卡框**。卡框是独立资产（B 类），插图画满版或透明，由我做合成。
3. **色板锁死**。每张图只用 §1.2 的五个色 + 三档点缀色。出现大面积粉紫/糖果色＝重出。

## 1. 视觉总纲

### 1.1 一句话风格锚

> **"霜里的工地，火边的街头。"**
> 工业感来自铁、焊疤、铆钉、旧篷布；二次元感来自赛璐璐硬边阴影与潮流剪裁；冻土感来自霜晶、白雾、冷蓝补光；炉火感来自橙红光溢与飘灰。

### 1.2 色板（必须锁死）

| 角色 | 色名 | HEX | 用在哪 |
|---|---|---|---|
| 基底 | 深蓝黑 | `#12161A` | 阴影、UI 底 |
| 基底 | 铁灰 | `#2E3438` | 金属、框体 |
| 基底 | 霜白 | `#E8EEF2` | 高光、雪、描边内白 |
| 点缀 | 炉火橙 | `#FF6A1F` | 火光、热源、危险前的暖 |
| 点缀 | 警示黄 | `#FFC72C` | 警戒条、读数、标签 |
| 点缀 | 苔绿 | `#6FCF97` | 苔庭、治疗、生机 |
| 点缀 | 霜蓝 | `#5BC8FF` | 冷光、界潮、罩灯 |
| 系统色（极少） | 荧光青 | `#00E5C1` | **只用于"系统/权限"**（权限灯、阀门读数） |
| 系统色（极少） | 警戒品红 | `#FF2D6F` | **只用于"致命/失效"**（归炉令、营地将破） |

### 1.3 材质四件套（每张图至少出现两种）

| 材质 | 表现 | 提示词用词 |
|---|---|---|
| 霜晶 | 六角结晶、边缘发白、有折射小亮点 | `frost crystals, rime, frozen vapor` |
| 锤痕铁 | 凹坑、焊疤、锈斑、哑光 | `hammered iron, weld scars, matte oxidized metal` |
| 旧篷布 | 补丁、磨毛边、粗缝线 | `patched canvas, frayed seams, waxed cloth` |
| 火盐 | 半透晶体、内部有流动光、裂纹发光 | `translucent glowing fire-salt crystal, inner luminous vein` |

### 1.4 光与构图（绝区零的技术核心）

- **单主光 + 强轮廓光**：主光从侧后打，轮廓光把角色从背景里"切"出来。
- **高对比**：暗部压到近黑，亮部留白；中间调少。
- **斜构图**：画面主体走对角线；地平线倾斜 3–8°。
- **动感截帧**：动作停在"中途"（未落地、未收势），配速度线与碎屑。
- **镜头**：35–50mm 等效；角色用微低机位（仰 5–10°）显得有分量；场景用大透视。

### 1.5 绝对禁止（出现即废图）

| 禁止 | 原因 |
|---|---|
| 任何文字/字母/数字/水印/签名 | 程序渲染文字 |
| 卡框、UI 边框、图标（除专门要求的 UI 资产） | 分层合成 |
| 写实照片感、3D 渲染塑料高光 | 破坏二次元统一 |
| 萌系、Q 版、大头身比 | 16+ 分级与题材不符 |
| 糖果粉彩、大面积紫粉渐变 | 违反色板 |
| 血腥、断肢特写、性化 | 红线 |
| 现代地球品牌、真实国旗、真实宗教符号 | 世界观污染 |
| 六指、断手、多腿 | 结构性废图 |

### 1.6 UI 语言（绝区零式，但换成"巡检仪器 + 街头贴纸"）

- **框体**：铁灰厚边框 + 四角铆钉 + 内侧 1px 霜白线；不是圆角，是**斜切角**（cut corner）。
- **贴纸层**：所有提示条像"贴在闸门上的纸条"——胶带、手写涂改、撕口。
- **读数**：荧光青小字 + 老式机械表盘；表盘玻璃有反光与裂纹。
- **状态色**：暖（炉火橙）＝可用；青（荧光青）＝系统；品红＝致命。
- **动效预留**：按钮要有"灯亮/灯暗"两态，不用阴影表达深度，用**发光**表达。

## 3. 母提示词（每次出图都拼在正文前面）

### 3.1 风格块（英文，直接抄）

```
Crisp high-end anime illustration in the style of a modern urban-fantasy action game (Zenless Zone Zero / HoYoverse production quality): clean cel-shaded rendering with hard-edged shadows, 2px ink outlines, strong single rim light, high-contrast chiaroscuro, subtle halftone dots and fine film grain, very slight 0.5px chromatic misregistration at the silhouette, saturated accent colors over a desaturated industrial base, dynamic diagonal composition, frozen motion capture, cool blue ambient fill with warm furnace-orange bounce light.
```

### 3.2 设定块（英文，直接抄）

```
Setting: "Ji-Yuan" (霁原), a frozen tundra city-state. Cliff bridges called 界桥 carry food, fire-salt and people between towns; periodic cold-and-space disturbances called 界潮 sweep the plains. Materials are patched canvas, hammered iron with weld scars, rime-covered rope, translucent glowing fire-salt crystals. Palette strictly limited to: frost white #E8EEF2, iron grey #2E3438, deep blue-black #12161A, furnace orange #FF6A1F, warning yellow #FFC72C, moss green #6FCF97, frost cyan #5BC8FF. Thin ice fog, drifting ash, breath vapor. No modern-Earth branding, no real-world logos.
```

### 3.3 负面块（英文，直接抄）

```
No text, no letters, no numbers, no watermark, no signature, no logos, no card frame, no UI overlay (unless explicitly requested), no photorealism, no 3D render look, no plastic specular highlights, no chibi or moe proportions, no pastel candy palette, no purple-pink gradients, no gore, no dismemberment, no sexualized content, no minors in suggestive framing, no extra fingers, no deformed hands, no melted faces.
```

### 3.4 参数建议

| 项 | 建议 |
|---|---|
| 模型 | GPT 图像模型（DALL·E 3 / GPT-4o 图像）优先；SDXL 类可复用同一提示词 |
| 画幅 | 严格按 §2.4，**不要用默认正方形** |
| 负向提示 | GPT 图像模型没有独立负向框时，把 §3.3 作为最后一段文字附上（写成 "Avoid: …"） |
| 透明 | GPT 图像模型不产真透明 → 让背景用**纯品红 `#FF00FF`**或**纯绿 `#00B140`**占位，我来抠 |
| 出图张数 | 每张资产一次出 4 张候选，挑 1 张；同批保持同一种子/同段提示词 |

## 14. 批处理指令（直接粘给 GPT）

> 你是本项目的概念美术。请严格按下列规则为「界桥远征·雁回之冬」批量出图。每次我发给你一个资产编号和一句话 Brief，你输出 **4 张候选**（同一种子风格）。
>
> **固定拼接**：每条提示词 = 「风格块」+「设定块」+「本条 Brief」+「Avoid: 负面块」。风格块与设定块我已在文档 §3 给出，你必须原样保留，不得改写。
>
> **硬性约束**：
> 1. 画面内**不得出现任何文字、字母、数字、水印**。
> 2. 除标注为"卡面框架 / UI / 图标"的资产外，**不得自行画卡框或 UI**。
> 3. 只用指定色板（`#E8EEF2 / #2E3438 / #12161A / #FF6A1F / #FFC72C / #6FCF97 / #5BC8FF`），另可极少使用 `#00E5C1`（系统）与 `#FF2D6F`（致命）。
> 4. 需要透明的地方用**纯品红 `#FF00FF`**填满，不要做棋盘格。
> 5. 画幅严格按该资产的规格；不要输出正方形，除非该资产要求 1:1。
> 6. 人物一律成年，服装实用、有磨损；**不做萌化、不做 Q 版、不做性化**。
>
> **输出格式**：每张图附一行索引，`编号 | 文件名 | 画幅`，例如 `ART-U-N01 | card_unit_N01.png | 3:4`。

## 15. 验收清单（我拿到图后逐条核）

| # | 检查项 | 不合格处理 |
|---|---|---|
| 1 | 有无文字/字母/数字 | 直接重出 |

## 16. 与 Unity 原型对接（我这边做）

| 步骤 | 内容 |
|---|---|
| 1 | 建 `Assets/Art/` 目录：`Cards/`、`UI/`、`Chars/`、`Scenes/`、`Icons/` |
| 2 | 卡面合成：`Image(插画) → Mask/内缩 → Image(框架) → TMP(牌名/费用/攻生/效果) → Icon(关键词)` |
| 3 | 卡框九宫格：`CF-*` 设 Sprite Border，随卡尺寸拉伸 |
| 4 | 图标染色：`UI-ICO-*` 单色白 → 用 `Image.color` 映射：暖=可用、青=系统、品红=致命 |
| 5 | 状态条/底板：九宫格 + 程序填充（营地条按数值裁切） |
| 6 | 立绘：`CHR-*` 进对话/结算；`CHR-C-*` 进卡面上角与头像位 |
| 7 | 图集打包：按类别打 Sprite Atlas（Cards / UI / Chars），控制 draw call |
| 8 | 命名对齐：文件名严格等于 §2.1 编号，禁止中文文件名（避免 Unity 导入问题） |

### 16.1 需要你确认的三个选择（会影响出图量）

1. **卡面插画是"人物画"还是"符号画"**？现在按本作设定走**人物/器物画**（更贵但更像成品）。若想省量，可改成"符号＋纹章"路线，出图量降 60%，但绝区零那种"角色感"会丢。
2. **P0 是否按 96 项做**？如果只想先看效果，可缩到 **24 项**（12 单位 + 6 卡框 + 3 UI + 3 场景）。
3. **透明通道**怎么给：GPT 出纯品红我来抠（现在这么写），还是你那边用能直出 PNG 透明的工具？
